## ✨ Fonctionnalités Principales (Features)

1. **Numérotation Séquentielle Automatique** : Code unique à 3 chiffres (`#001`, `#002`, etc.) et QR code généré instantanément.
2. **Impression Thermique de Stickers (50x30mm)** : Prêt pour imprimante ticket/étiquette thermique Bluetooth/ESC-POS avec aperçu direct.
3. **Palette Douce & Épurée (Clean Soft White)** : Inspirée d'Apple et Google pour le confort visuel du technicien à l'établi.
4. **Synchronisation Cloud Supabase** : Synchronisation bidirectionnelle avec base de données PostgreSQL Supabase pour affichage sur PC ou site web.
5. **Mode Archive & Recherche Rapide** : Recherche instantanée par code, numéro de téléphone marocain (`06...` / `+212`), marque ou nom du client.
6. **Sauvegarde Locale Room & Export JSON** : Fonctionne 100% hors-ligne (Offline-first) avec export/import JSON.
7. **Bilingue Complet** : Arabe (العربية) et Français.
